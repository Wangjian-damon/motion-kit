## 1 一句话

复刻经典机场出发屏与 Braun 机械翻页钟：每一位数由上下独立裁切静页与两片居中转轴翻页叶组成，数值变更时仅变化的那一位触发 3D 下翻接力并带真实的折角压暗阴影。

## 2 交互问题

**倒计时、实时在线人数或大屏 KPI 跳变时，直接替换文字缺少仪式感，普通上下滚动又太像老套老虎机；而手写翻牌动效最容易踩“翻到一半旧字新字穿帮”或“未变化的十位也跟着乱翻”的坑。** 把一次翻牌拆成严格的四层结构与两段 90° 接力（上半旧字 `0° → -90°` 加速落下，下半新字 `90° → 0°` 减速弹停），只在 `next[i] !== cur[i]` 的位上触发，机械质感立刻拉满。

## 3 手感来源

| 取什么 | 丢什么 |
|---|---|
| 上半翻折加速下落（`cubic-bezier(0.55, 0.05, 0.9, 0.6)`）模拟重力，下半着陆减速收住（`cubic-bezier(0.16, 1, 0.3, 1)`） | 一条匀速 `linear` 动画到底（像软塑料片而不是金属翻牌） |
| 翻到 90° 处叠加 `filter: brightness(0.45)` 压暗再回亮，模拟真实物理页片背光阴影 | 纯平面旋转无明暗变化显得扁平廉价 |
| 只对发生变化的位触发翻页，高位未变保持纹丝不动 | 每次更新把所有位数一起重建重翻 |

## 4 参数与为什么

| 参数 | 值 | 为什么是这个值 |
|---|---|---|
| 两段接力时长 | 上半 `220ms` + 下半 `220ms`（延迟 `215ms`） | `5ms` 极微重叠防止中轴交接处出现 1 帧空闪；总计 `435ms` 赶得上 1 秒一跳的时钟节奏 |
| 单格透视深度 | `perspective: 420px` | 让 76px 高的翻牌在折到 45° 时呈现利落的梯形透视张力，不至于过度畸变 |
| 中缝分割线 | 居中 `1.5px` 深黑横缝（`z-index: 6`） | 还原机械翻页牌物理铰链间隙，天然掩护上下两半裁切接缝 |
| 定长位规范化 | `splitFlapDigits(value, pad)` + `tabular-nums` | 无论传入负数、`NaN` 或短数字，永远产出稳定位数字符数组，卡片宽度零跳动 |

## 6 降级契约

**走 `3d` 层专属契约：取消 3D 翻折，直接原地干净换字。**

`prefers-reduced-motion: reduce` 下关闭两段翻折关键帧动画，数据更新时数字直接干净切换，保留机械翻牌卡片外观与中缝结构，不丢失任何实时数值。

## 7 容易做错的地方

**① 上下四层内容赋值顺序搞错，导致翻到一半露出旧字或新字提前穿帮。**
正确时序：开始翻页瞬间，**上静页**立刻显示新字（被上翻叶挡住），**下静页**保持旧字；**上翻叶**显示旧字从 `0° → -90°` 折下露出上静页新字；到中点后**下翻叶**显示新字从 `90° → 0°` 盖住下静页旧字；动画结束后把下静页同步为新字。

**② 没设 `backface-visibility: hidden` 导致翻过 90° 后看到镜像反字。**
两片翻页叶必须设置 `backface-visibility: hidden`（含 `-webkit-` 前缀），过垂直面自动隐藏。

**③ 连续快速触发 `.set()` 忘记先清理旧 `setTimeout` 或强制 reflow 重置动画。**
必须维护定时器集合并在 `destroy()` 里清理，避免卸载后残留回调改写已移除 DOM。

## 8 AI 提示词

**用途**：在任意前端项目里实现零依赖、四层两段接力的 3D 机械翻页时钟 / 翻牌计数器。

```text
实现零依赖的 3D 机械翻页时钟 / 翻牌器（Split-Flap 3D Mechanical Flip Card）。

原理一句话：每位翻牌由上静页、下静页、上翻叶、下翻叶四层构成，内部文字高度 200% 各自裁切上下半；数值变化时仅变更位触发两段 90° 3D 接力翻折（重力加速下折 + 减速着陆 + 折角压暗阴影）。

做法：
1. 纯函数 splitFlapDigits(value, pad = 2)：
   - pad 钳制在 [1, 8]；数字取 Math.max(0, Math.floor(value))（非有限数按 0）左侧补零截断为定长数组；字符串转大写去非字母数字后补零截断。
2. 四层 DOM 与 CSS 3D 结构（单格 perspective: 420px，居中 1.5px 铰链黑缝）：
   - 上静页 / 上翻叶：top: 0; height: 50%; overflow: hidden; 内层文字 height: 200%; top: 0;
   - 下静页 / 下翻叶：bottom: 0; height: 50%; overflow: hidden; 内层文字 height: 200%; bottom: 0;
   - 两片翻叶均设 backface-visibility: hidden；上翻叶 transform-origin: 50% 100%，下翻叶 transform-origin: 50% 0% 且默认 rotateX(90deg)。
3. 严密四层赋值与两段接力动画（仅当 next[i] !== cur[i] 时触发）：
   - 翻转起点：上静页 = 新字，下静页 = 旧字，上翻叶 = 旧字，下翻叶 = 新字；
   - 上翻叶 220ms cubic-bezier(0.55, 0.05, 0.9, 0.6)：rotateX(0deg) brightness(1) -> rotateX(-90deg) brightness(0.45)；
   - 下翻叶 220ms 延迟 215ms cubic-bezier(0.16, 1, 0.3, 1)：rotateX(90deg) brightness(0.55) -> rotateX(0deg) brightness(1)；
   - 460ms 结束后将下静页与上翻叶同步为新字并移除翻转态类。
4. 降级与清理：
   - prefers-reduced-motion: reduce 禁用两段翻折关键帧，直接完成数值更新。
   - destroy() 清理全部未完成 timer 防止内存泄漏。

硬要求：
- 必须严格按四层时序更新文字，确保翻折前后与中点瞬间绝不出现新旧字穿帮。
- 仅发生变化的位触发翻页，未变位严禁重播动画；数字必须开启 tabular-nums。
- 翻页叶必须设置 backface-visibility: hidden 与折角压暗阴影。

验收：
- 倒计时或点击 +1 / 随机切换时，只有变动的位数发生干脆利落的机械翻折，未变动位纹丝不动。
- 翻折经过 90° 中缝时有真实阴影变暗与无缝接力，无白闪、无镜像反字。
- 开启减弱动效后数值干净切换无晃动；卸载后无残留定时器报错。
```

**别让它做的**：

- 别用单个 `div` 直接 `rotateX(-180deg)` 假装翻牌 —— 真实翻牌是上下两半在水平中缝处翻折，整卡旋转会失去机械感且字会上下颠倒。
- 别在只变个位时把十位、百位也一起翻一遍 —— 极其吵闹且违背物理机械结构。
- 别忘了在上下翻页交界留 `5ms` 重叠（`220ms` 与 `215ms` 延迟）—— 严丝合缝设为 `220ms` 时部分浏览器帧对齐会漏出 1 帧黑缝。

Without MotionKit Skill

普通 AI 凭空写动效时常踩的坑

  • 直接动画 width / height / bottom，整张表格或抽屉每帧重排掉帧
  • 漏掉 pointercancel，系统边缘手势抢走事件后弹窗自己误关
  • 实时数字不加 tabular-nums，接口秒回时转圈闪一帧像抽风
  • 要么完全不写 prefers-reduced-motion，要么一刀切把玻璃导航栏删没
With MotionKit Skill · Auto-Applied

装上 MotionKit 后 AI 一次交付的标准

  • 全程 transform / clip-path / CSS 变量 合成器运动，零动画库依赖
  • 自带经过单测的物理常量（c=0.55 橡胶阻尼、28% / 0.55px/ms 速度投影）
  • grid-area: 1/1 零宽跳 + 400ms 防闪 + 320ms 封顶级联，不拖慢扫读
  • 三套分级降级契约（Motion 减 / 3D 归零 / 玻璃冻住）与可观测验收清单

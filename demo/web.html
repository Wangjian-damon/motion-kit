05 / 进出场

纯 CSS 的弹层，不需要动画库

@starting-style + transition-behavior: allow-discrete 让 display 也能参与过渡 —— Baseline 2024 起已经可用。

为什么不用 JS 动画库

进出场只需要「从初始态过渡到终态」。浏览器原生支持后，少一个依赖、少一次布局查询，还能自动跟随系统主题变化。

08 / 揭示

入场不止是「往上滑 16px」

视差、遮罩擦除、线条描绘、逐词拆分、模糊入场。 每种都能被 IntersectionObserver 触发，也都能在减弱动效下退化。

视差卡 SCROLL ME

两层不同 strength，滚动时产生纵深。 rAF 合批，一帧只算一次。

遮罩擦除 · clip-path

clip-path: inset() 过渡，不动 transform， 对图片和视频都安全。data-from 换方向。

SVG 线条描绘

stroke-dashoffset

图表、logo、流程线都能用。给 path 一个足够大的 dasharray 即可。

模糊入场

blur 12px → 0 比纯位移更「贵气」

--mk-blur 控制起始模糊量。

逐词拆分入场

好的动效不是让元素飞起来，而是让人知道东西从哪来。

v-mk-split="'word'" 也可传 'char' / 'line'。 拆分只做一次，之后零计算 —— 不需要 GSAP SplitText。
